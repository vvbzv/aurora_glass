# Aurora Glass

Aurora Glass is a graphite-blue glass theme for Obsidian, customized on top of
Oczko24's Obsidian Transparent theme.

Repository: https://github.com/OtmiVi/aurora_glass

## Highlights

- Dark and light graphite-blue glass palettes.
- Style Settings support for presets, background type, blur, tint, width,
  scrollbars, mobile tweaks, and animation toggles.
- Transparent, gradient, solid-color, and custom-image background modes.
- Tuned settings modal, community theme browser, tabs, file explorer, graph,
  canvas, callouts, code blocks, marks, and inline code.
- Compatibility fixes for Style Settings, Make.md, MySnippets, Day Planner,
  Remotely Save, Notebook Navigator, and Enchanted Animations.

## Install

1. Put this folder in `.obsidian/themes/Aurora Glass`.
2. In Obsidian, open `Settings -> Appearance -> Themes`.
3. Select `Aurora Glass`.

For the full control panel, install the Style Settings community plugin.

## Recommended Setup

- Preset: `Base` for the graphite-blue look.
- Background Style: `Auto` for mode-specific defaults.
- UI Elements Blur: `20px` to `35px` for a good balance between glass and speed.
- Background Blur: lower it on older laptops or mobile devices if animations feel heavy.
